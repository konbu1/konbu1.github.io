公開の仕組み

GitHub Pages — 無料で広告なし

このブログの置き場

置き場は GitHub Pages です。静的サイトなので、記事はHTMLファイルとして置くだけで公開できます。サーバー代はかからず、プラットフォームの広告も入りません。最初は無料の github.io ドメインで始められます。

  • 完全無料（静的ホスティング）
  • 独自ドメインもあとから無料で接続できる
  • 記事の原本はGitで管理でき、履歴が残る

公開までの手順

  1. 1
    GitHubアカウントを作るメールアドレスで登録します（アカウント作成は本人の作業です）。
  2. 2
    リポジトリを作る<ユーザー名>.github.io という名前で公開リポジトリを作成します。
  3. 3
    このページを置くindex.html と画像をリポジトリへアップロード（push）します。
  4. 4
    Pagesを有効にするSettings → Pages で公開元を選ぶと、数分でURLが発行されます。
  5. 5
    記事を足していく記事ファイルを1本ずつ追加してpushするだけ。以降はこの繰り返しです。

広告・PR表示について

景品表示法（ステマ規制）への対応

このブログの表示ルール

アフィリエイトリンクを含む記事では、タイトルのすぐ下・記事の冒頭に、広告であることが分かる表示を入れます。末尾だけの表示、小さく薄い表示はしません。

リンクを載せる記事に表示する文面（テンプレート）：

この記事にはアフィリエイトリンクが含まれています。リンクから商品を購入すると、売上の一部が当ブログに還元されることがあります。価格や在庫は購入時のものをご確認ください。

当ブログはAmazonのアソシエイトとして、適格販売により収入を得ています。（この一文は、Amazonの商品リンクを実際に載せた記事にだけ表示します）

  • リンクには「広告」「PR」と分かる表記を付けます
  • 自分でリンクを踏んで買う（自己購入）はしません
  • リンクの隠蔽・偽装、強制的な別サイトへの遷移はしません
  • 価格や性能の数字は、根拠のあるものだけを書きます

提携プログラムは A8.net / もしもアフィリエイト / Amazonアソシエイトを予定しています。登録と本人確認はブログ運営者本人が行います。リンクは登録が済んでから、実際に紹介できるものだけを置きます。

広告について：この記事には現在、アフィリエイトリンクを掲載していません。リンクを載せる場合は、この場所にPR表示を入れてから公開します。
